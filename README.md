# SpiroBrixx Construction System

The _SpiroBrixx_ building blocks enable makers, scientists and artists to prototype there mechanical engineering and lab projects in minutes.

## Build and Make

Just run:

```bash
./build.sh
```

to generate the 3D printable STL (or OBJ) files in `gen/mech/spirobrixx/`.

Recommended print parameters:
* Material: PETG
* Dry the Material at least 24 h before printing.
* Nozzle: 0.4 mm
* Inner Perimeter: 0.8 mm
* Infill: 0.8 mm
* Standard values for all other parameters
